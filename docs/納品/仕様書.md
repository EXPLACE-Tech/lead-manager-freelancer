# freelancer-leads 仕様書

対象: 株式会社EXPLACE
最終更新: 2026-09-01・版2

---

## 1. 概要

Freelancer.com上の募集中案件を取得し、日本語タイトル訳・カテゴリ分類・予算の日本円換算を行って、
専用のGoogleスプレッドシート「案件管理 Freelancer」に書き込む、**人手起動のClaude Code Skill**。

対象読者は開発者・運用担当者。エンドユーザー向けの使い方は `説明書.md` を参照。

---

## 2. 全体構成

```
[人] --「Freelancerの案件リストして」--> [Claude Code] --(A)取得/翻訳/分類/換算--> [Claude Code]
                                                                    |
                                                          (B) HTTPS POST (JSON)
                                                                    v
                                                [Google Apps Script Web App (doPost)]
                                                                    |
                                                          (C) スプレッドシートへappendRow
                                                                    v
                                                     [Googleスプレッドシート「案件管理 Freelancer」]
```

- **(A)取得〜換算はすべてClaude Code側（ローカルPC）で行う。** GAS側にはFreelancer.com APIを叩くコードは無い
- **(B)** Claude CodeからGASへは、書き込み専用のWeb Appエンドポイントに1回のPOSTで送る
- **(C)** GASはシートへの追記と重複ガードのみを担当する「受け口」

この構成にした理由: 当初はGAS側が1時間ごとに自動でAPIを叩く設計を検討したが、無人実行にはClaude Codeの
確認プロンプトを省略する権限緩和が必要になるため見送り、**人が明示的に実行した時だけ動く**現行方式にした。

## 4. スプレッドシート仕様

### 4.1 `案件リスト`シート（15列）

| # | 列名 | 埋まるタイミング |
|---|---|---|
| A | 配信日時 | 自動（取得時刻） |
| B | 案件No | 自動（`FL-<Freelancer.com案件ID>`） |
| C | 案件タイトル | 自動（原文） |
| D | 案件タイトル(日本語訳) | 自動（Claude Codeが翻訳） |
| E | カテゴリ | 自動（Claude Codeが5分類のいずれかに判定） |
| F | 予算 | 自動（原通貨表記） |
| G | 予算(日本円換算) | 自動（実行時点の為替レートで概算） |
| H | 応募期限 | 自動（投稿日+7日の概算） |
| I | URL | 自動 |
| J | ステータス | 手動（プルダウン、7段階） |
| K〜N | 応募日/返信日/商談日/成約日失注日 | 手動 |
| O | 備考 | 手動 |

### 4.2 カテゴリ体系（5分類）

`Web制作` / `システム開発` / `デザイン` / `マーケティング` / `その他` の5つ。
発注ナビ案件で使っている統一カテゴリ7分類（ライティング・未分類を含む）のサブセットで、
Freelancer.com運用ではライティング・未分類は使わない方針（2026-09-01・社長指示）。

判定はタイトル本文とFreelancer.com側のURLスラッグ（例: `/projects/web-design/...` の `web-design`）を
手がかりに、Claude Codeがその都度判断する。キーワードの機械的マッチではなく、文脈判断。

判定例:
- サイト構築・CMS・WordPress・ランディングページ → Web制作
- API連携・自動化・アプリ開発・バックエンド → システム開発
- ロゴ・3Dレンダリング・モックアップ・ブランディング → デザイン
- SEO・広告運用・SNS運用・メールマーケティング → マーケティング
- 動画編集・法務相談・データ入力・VA業務など非開発作業 → その他

### 4.3 集計シート

カテゴリ×ステータスのCOUNTIFSで転換率（返信率・商談化率・成約率）を自動計算する。発注ナビ版と同一の仕組み。

## 5. 取得・フィルタ・重複排除ロジック（トークン節約設計）

**目的:** 案件情報の再読み込み・再翻訳・再分類にトークンを浪費しないこと（2026-09-01・社長指示）。

1. 実行のたびに、まずシート上の`案件No`列の最大値（数値部分）を`lastMaxId`として調べる
2. 検索クエリ（既定4件: `web development` / `wordpress` / `automation script` / `api integration`）ごとに
   Freelancer.comの検索APIを叩き、結果を案件ID降順に並べ直す
3. 案件IDが`lastMaxId`以下になった時点でそのクエリの処理を打ち切る（それ以降は取得済みの古い案件のため、
   翻訳・分類などの処理を一切行わない）
4. **`type`が`hourly`（時給）の案件はこの時点で除外する。**単価（`fixed`）案件のみをリスト化する方針
   （2026-09-01・利用者指示）。除外された案件は翻訳・分類などの処理を一切行わない
5. 残った「新規候補」を案件IDで重複除去してから、翻訳・分類・円換算を行う

単価/時給の判定は「予算」列の表記に反映される（時給案件は末尾に`/h`が付く）。誤って時給案件が入った場合は、
Web Appの削除API（7.参照）で案件No指定で削除できる。

この設計により、2回目以降の実行では新着分だけが処理対象になり、既知の案件を毎回読み直すことがない。

**制約:** 1クエリあたりの取得件数上限は20件（`SKILL.md`内に明記、変更可）。前回実行からの新着数が
この上限を超えていた場合、超過分は次回実行に持ち越されず取りこぼす可能性がある（実行頻度を上げることで軽減）。

## 6. 日本円換算

- 為替レートは無料・無認証のAPI [`open.er-api.com`](https://www.exchangerate-api.com/docs/free) を実行のたびに1回取得（1日1回更新）
- 静的な固定レート表は使わない。**実行時点のレートでの概算値**であり、金融取引の根拠にはできない
- 計算式: `JPY換算額 = 原通貨の金額 ÷ (対USDレート) × (USDの対JPYレート)`

## 7. セキュリティ / Web Appのエンドポイント仕様

- Web Appは`doPost`のみを公開し、`secret`（`webapp-config.json`の値と、Apps Script側が`PropertiesService`に自動生成・保存したトークンが一致することを確認）で簡易認証する
- **トークンは手動生成不要。** `setup()`初回実行時にApps Script自身がランダムなUUIDベースの値を生成し、そのプロジェクト内にのみ保存する（コード・gitには残らない）。生成された値は`setup()`の完了メッセージに表示される（`docs/納品/導入手順.md`参照）
- 正しいトークンを知らない第三者はデータを書き込めない（ただし本番運用では、より強固な認証への切り替えを推奨）
- Web Appの実行権限は「デプロイしたアカウントとして実行」「アクセス可能ユーザー: 全員」
- リクエストボディで2種類の操作を受け付ける（詳細は`gas-freelancer/WebApi.gs`冒頭のコメント参照）
  - `{"secret": "...", "leads": [...]}` — 案件の追記（案件No重複ガードあり）
  - `{"secret": "...", "deleteCaseNos": ["FL-xxxxx", ...]}` — 案件No指定での削除（誤って入ったデータの手直し用）
- 読み取り専用のAPIは提供していない（シートの内容確認はGoogle スプレッドシートを直接開くか、Google Drive経由で行う）

## 8. 既知の制約・注意点

- 応募期限は「投稿日+7日」の概算。Freelancer.com側の実際の入札受付期間（bidperiod）が7日以外の案件では正確でない
- カテゴリ分類・日本語訳はAIによる都度判断であり、機械的なルールベースではない（案件によって表記揺れの可能性あり）
- Freelancer.comの検索APIはログイン不要で叩けるが、公式に高頻度アクセスを許可する記載はないグレーゾーン。人手起動のみとし、無人の自動巡回は行っていない
- 為替レートは日次更新のAPIに依存。金額は目安として利用すること
