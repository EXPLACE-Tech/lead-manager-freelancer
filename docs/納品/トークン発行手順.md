# SHARED_SECRET（Web App認証トークン）の発行手順

対象: 株式会社EXPLACE
最終更新: 2026-09-01（版2・自動生成方式に変更）

---

## これは何か

`freelancer-leads` は、Claude Codeが取得・翻訳・分類したデータを、Google Apps Scriptの
Web App（`gas-freelancer/WebApi.gs`）にPOSTして書き込みます。このとき「正しい依頼元からのリクエストか」を
簡易的に確認するために、共有の合言葉（トークン）を使います。これが `SHARED_SECRET` です。

**手動でトークンを生成する必要はありません。** `setup()`を実行すると、Apps Script自身が
ランダムなトークンを自動生成し、そのApps Scriptプロジェクト内だけ（`PropertiesService`）に
保存します。コードにも、gitにも、一切残りません。

---

## 手順

### 1. `setup()` を実行する

`docs/セットアップ手順_Freelancer.md` の手順3どおり、Apps Scriptエディタで `setup` 関数を実行する。

完了メッセージ（実行ログ、または初回はダイアログ）に、以下のように表示される。

```
■認証トークン（webapp-config.jsonのsharedSecretにこの値をそのままコピーする）:
a1b2c3d4e5f6...
```

### 2. `webapp-config.json` に貼る

`gas-freelancer/webapp-config.example.json` をコピーして `gas-freelancer/webapp-config.json` を作り
（このファイルは`.gitignore`対象＝gitには含まれない、各自のローカルにだけ置く）、
`sharedSecret` に手順1で表示された値をそのまま貼る。`webAppUrl` にはWeb Appデプロイ後に発行されるURLを入れる。

デプロイ手順そのものは `docs/セットアップ手順_Freelancer.md` を参照。

### 3. 動作確認

`docs/セットアップ手順_Freelancer.md` の「動作確認」セクションに沿って、テストデータを送ってみる。
`{"added":1,"skipped":0}` が返ればトークンは正しく設定できている。`unauthorized` が返る場合は
`webapp-config.json`の値がsetup()実行時に表示された値と一致しているか確認する
（表示された値を忘れた場合は、Apps Scriptエディタで`getSharedSecret_`関数を実行すれば再確認できる。
再実行しても値は変わらない＝毎回同じトークンが返る）。

---

## 注意

- トークンは第三者に共有しない（知っていれば誰でもスプレッドシートに書き込めてしまう）
- 万一漏洩した場合は、Apps Scriptエディタで以下を1回実行してトークンを再発行する（`webapp-config.json`側も新しい値に更新すること）
  ```
  PropertiesService.getScriptProperties().deleteProperty('SHARED_SECRET');
  ```
  次に`getSharedSecret_()`が呼ばれたとき（＝次の`/freelancer-leads`実行時）に新しいトークンが自動生成される
