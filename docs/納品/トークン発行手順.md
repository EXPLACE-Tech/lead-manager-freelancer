# SHARED_SECRET（Web App認証トークン）の発行手順

対象: 株式会社EXPLACE
最終更新: 2026-09-01

---

## これは何か

`freelancer-leads` は、Claude Codeが取得・翻訳・分類したデータを、Google Apps Scriptの
Web App（`gas-freelancer/WebApi.gs`）にPOSTして書き込みます。このとき「正しい依頼元からのリクエストか」を
簡易的に確認するために、共有の合言葉（トークン）を使います。これが `SHARED_SECRET` です。

**このトークンは各自で発行してください。** 納品コードには実際の値を含めていません
（`gas-freelancer/Config.gs` にはプレースホルダが入っています）。

---

## 手順

### 1. トークンを生成する

ターミナル（PowerShell / コマンドプロンプト / bash いずれでも可）で以下を実行する。

PowerShellの場合:
```
-join ((48..57)+(97..102) | Get-Random -Count 32 | % {[char]$_})
```

Pythonが使える場合:
```
python -c "import secrets; print(secrets.token_hex(16))"
```

どちらも32文字の英数字（例: `8a62aa92a34e8e220600df9b6b0f9f7e`）が出力される。これがトークン。

### 2. `gas-freelancer/Config.gs` に貼る

Apps Scriptエディタで `Config.gs` を開き、末尾の

```
const SHARED_SECRET = 'ここに生成したトークンを貼る（...）';
```

の `'...'` の中身を、手順1で生成した値に差し替えて保存する。

### 3. `webapp-config.json` を作る

`gas-freelancer/webapp-config.example.json` をコピーして `gas-freelancer/webapp-config.json` を作り
（このファイルは`.gitignore`対象＝gitには含まれない、各自のローカルにだけ置く）、
`sharedSecret` に手順1と**同じ値**を、`webAppUrl` にはWeb Appデプロイ後に発行されるURLを入れる。

デプロイ手順そのものは `docs/セットアップ手順_Freelancer.md` を参照。

### 4. 動作確認

`docs/セットアップ手順_Freelancer.md` の「動作確認」セクションに沿って、テストデータを送ってみる。
`{"added":1,"skipped":0}` が返ればトークンは正しく設定できている。`unauthorized` が返る場合は
手順2と3の値が一致しているか確認する。

---

## 注意

- トークンは第三者に共有しない（知っていれば誰でもスプレッドシートに書き込めてしまう）
- 万一漏洩した場合は、手順1からやり直して新しいトークンに差し替える（Config.gsとwebapp-config.jsonの両方を更新すること）
