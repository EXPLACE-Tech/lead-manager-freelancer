# freelancer-leads 使い方ガイド

対象: 株式会社EXPLACE
最終更新: 2026-09-01

---

## これは何か

Freelancer.com で現在募集中の案件を自動収集し、①日本語タイトル訳 ②カテゴリ分類 ③予算の日本円換算
まで行ったうえで、専用のGoogleスプレッドシートに一覧化するツールです。

発注ナビの案件を管理している既存の「案件管理」スプレッドシートと同じ考え方（応募〜成約をステータスで
追いかけ、カテゴリ別の転換率を蓄積する）を、Freelancer.com向けに作ったものです。

---

## 使い方

1. Claude Code を `lead-manager` プロジェクトのディレクトリで起動する
2. チャットで **「Freelancerの案件リストして」** と話しかける（`/freelancer-leads` でも可）
3. 数十秒〜数分で完了する。結果はスプレッドシートに新着行として追加される

実行するたびに**新着分だけ**が追加されます。前回までに取得済みの案件は読み直さないので、
毎日/毎週など気軽に何度でも実行して問題ありません。

---

## 結果の見方

スプレッドシート「案件管理 Freelancer」:
https://docs.google.com/spreadsheets/d/1uBh3bkY5eO62gtQQgSyHxbgPbrSG2jwQwibY3nl74mY/edit

| 列 | 内容 |
|---|---|
| 配信日時 | このツールが取得した日時 |
| 案件No | `FL-<Freelancer.comの案件ID>` |
| 案件タイトル | 原文（英語等） |
| 案件タイトル(日本語訳) | 日本語訳 |
| カテゴリ | Web制作 / システム開発 / デザイン / マーケティング / その他 のいずれか |
| 予算 | Freelancer.com表記の原通貨（例: `USD 30〜250`） |
| 予算(日本円換算) | 実行時点の為替レートでの概算（例: `約4,800円〜39,900円`） |
| 応募期限 | 投稿日+7日の概算（Freelancer.comの標準的な入札受付期間） |
| URL | 案件詳細ページ |
| ステータス | 配信検知 → 応募済 → 返信あり → 商談設定 → 商談実施済 → 成約/失注（手動更新） |
| 応募日〜備考 | 手動で追記していく運用列 |

シートには他に、カテゴリ別の応募文テンプレート（`テンプレート_Web制作` 等）と、
転換率を自動集計する `集計` シートも用意されています。

## 前提条件

- Claude Code CLIが使える状態であること
- `lead-manager` リポジトリがローカルにあること（Skill本体はこの中にある）
- 上記スプレッドシートへのアクセス権（Google Driveの共有設定）
- Google Apps Script の書き込み用Web Appは既にデプロイ済み（設定は `gas-freelancer/webapp-config.json`）

---

## 注意事項

- 予算の円換算・応募期限は**目安**です。実際の入札条件は必ずFreelancer.comの案件詳細ページで確認してください
- カテゴリ分類はAIによる判定です。まれに実態と異なる分類になることがあります（気づいた場合はシート上で手動修正して問題ありません。次回実行時に上書きされることはありません）
- Freelancer.comの検索APIは公式に高頻度アクセスを許可した記載がないグレーゾーンです。人が明示的に実行した時だけ動く設計になっており、自動巡回・無人実行は行っていません

詳しい技術仕様は `仕様書.md` を参照してください。
