# lead-manager リード処理の手順（Claude Code + claude-in-chrome）

`案件リスト`シートの **カテゴリ・予算・応募期限** を埋める作業の手順。GAS側では自動化しない
（発注ナビの案件詳細ページはログインが必要で、GAS の `UrlFetchApp` はブラウザのログインセッションを
持てず取得できないことを検証済み。`docs/進捗.md` 参照）。代わりに、社長が使っているブラウザの
ログイン済みセッションを Claude Code + claude-in-chrome で操作し、人力（Claude）で埋める。

---

## 前提

- Chrome で発注ナビにログイン済みであること（社長がいつも使っているプロファイル）
- claude-in-chrome 拡張機能がインストール済み・`developer.hnavi.co.jp` への権限が許可されていること
- スプレッドシートのURLが `docs/進捗.md` に記録されていること

## 実行タイミング

**都度手動トリガー。自動実行はしない。** 「Claude Codeの入ったPCが常に起動している」という前提を置かない設計にしているため、社長がセッション中に「lead-manager のリード処理して」のように声をかけたときだけ動く。

## 手順（Claudeが行う）

1. `案件リスト`シートを開き、カテゴリ・予算・応募期限のいずれかが空欄の行を洗い出す
2. 各行のURL列を、claude-in-chromeで開く（発注ナビの案件詳細ページ。ログイン済みタブなので詳細まで見えるはず）
3. ページから予算・応募期限・案件本文を読み取る
4. 案件タイトルだけでなく本文全体を読んだ上で、統一カテゴリ7分類のどれに当たるか判断する
   - `Web制作` / `システム開発` / `デザイン` / `ライティング` / `マーケティング` / `その他` / `未分類`
   - どれにも当てはまらない・判断がつかない場合のみ `未分類` にする
5. スプレッドシートの該当セル（カテゴリ・予算・応募期限）に書き込む
6. 全件終わったら処理件数と、判断に迷った案件があれば個別に報告する

## 注意点

- ログインが切れている場合は案件詳細が取得できない（ログイン画面が返ってくる）。その場合は社長に再ログインを依頼してから再実行する
- あくまで人間が普段ブラウザで見る操作をClaudeが代行しているだけという整理。案件詳細ページの自動巡回・保存等はしない（都度その場で読んで転記するのみ）
- 案件No・タイトル・URL・配信日時・ステータスはこれまで通りGASが自動で入れる。この手順が触るのはカテゴリ・予算・応募期限の3列だけ
